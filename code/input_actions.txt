  GOBLIN CHAIN — Custom Input Actions
  Set these in S&box: Project Settings → Input
═══════════════════════════════════════════════════════

These CUSTOM actions must be added manually in the S&box editor.
Standard actions (Forward, Backward, Left, Right, Jump, Run,
Crouch, Use, Attack1, Voice) are built-in.

┌────────────────┬─────────────┬──────────────────────────┐
│ Action Name    │ Default Key │ Used By                  │
├────────────────┼─────────────┼──────────────────────────┤
│ Trade          │ T           │ PlayerInput → TradePanel  │
│ OpenMarket     │ M           │ PlayerInput → Market UI   │
│ Sabotage       │ Q           │ PlayerInput → EMP throw   │
│ PlaceRig       │ E           │ PlayerInput → Rig spawn   │
│ CycleToken     │ Tab         │ PlayerInput → Token cycle  │
└────────────────┴─────────────┴──────────────────────────┘

NOTE: "Use" (default: E) is a built-in action already bound to E.
      "PlaceRig" is separate so we can distinguish interaction
      from rig placement. You may map both to E if you prefer
      context-sensitive behavior (handled in PlayerInput.cs).

Standard S&box actions used by GoblinPlayer.cs:
  Forward    (W)
  Backward   (S)
  Left       (A)
  Right      (D)
  Jump       (Space)
  Run        (Shift)
  Crouch     (Ctrl)
  Use        (E)       — interaction raycast
  Voice      (V)       — push-to-talk
